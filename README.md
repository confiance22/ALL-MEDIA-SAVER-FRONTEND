# ALL-MEDIA-SAVER-FRONTEND

Frontend for the family media saver (TikTok, Instagram, YouTube, X). Vite + React
(Tailwind CSS), deployed to Vercel. Paste a link, get a media card with a cover
preview, then Save to Downloads.

## Env

`VITE_BACKEND_URL` = the deployed backend URL (Render), set at build time.

## Dev

```
npm install
npm run dev
```

## Build

```
npm run build   # outputs to dist/
```
